# MoneyGrip design system

MoneyGrip uses the **Editorial Grid** visual language: cool neutral surfaces, restrained teal
accents, compact information hierarchy and a soft charcoal dark mode. Color carries meaning
in charts and status, while structure and typography do most of the visual work.

## Principles

- Make financial information understandable without assuming financial knowledge.
- Meet WCAG 2.2 AA and support complete keyboard navigation.
- Never use color as the only indicator of gain, loss, selection or validation.
- Keep visible strings in the consuming application so every component can be localized.
- Use Belgian defaults (`nl-BE`, EUR, `Europe/Brussels`) without limiting supported locales.
- Add motion only when it explains a state change or action.

Use the toolbar to inspect every story in Dutch or English and in light, dark or system mode.
